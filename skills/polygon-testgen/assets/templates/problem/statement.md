# pA. 最大區間和 (Max Subarray)

## Legend

給定一個長度為 $N$ 的整數序列 $a_1, a_2, \ldots, a_N$，請找出一個**非空**的連續區間，使區間內數字總和最大，並輸出這個最大總和。

## Input format

第一行有一個正整數 $N$（$1 \le N \le 2 \times 10^5$）。

第二行有 $N$ 個整數 $a_1, \ldots, a_N$（$|a_i| \le 10^9$），以空白分隔。

## Output format

輸出一個整數，代表最大的區間和。

## Scoring

| 子題 | 分數 | 額外輸入限制 |
|---|---|---|
| 1 | 20 | $N \le 100$ |
| 2 | 30 | $a_i \ge 0$ |
| 3 | 50 | 無特殊限制 |
