# 第三題：彩色圍籬 (Fence)

小明家的圍籬由 N 片木板排成一列，每片木板漆成一種顏色，以小寫英文字母表示。小明想要讓圍籬上出現一段盡可能長、而且顏色全部相同的連續木板。他最多可以重新粉刷 K 片木板（每片可以改成任意顏色）。

請問粉刷之後，顏色全部相同的連續木板最長可以有幾片？

## 輸入說明

第一行有兩個整數 N、K（1 ≤ N ≤ 200000，0 ≤ K ≤ N）。
第二行是一個長度為 N 的字串 S，只包含小寫英文字母，代表每片木板的顏色。

## 輸出說明

輸出一個整數，代表最長的長度。

## 範例輸入 1

```
8 2
aabacbaa
```

## 範例輸出 1

```
5
```

## 範例輸入 2

```
5 0
abcde
```

## 範例輸出 2

```
1
```

## 評分說明

| 子題 | 分數 | 額外限制 |
|---|---|---|
| 1 | 20 | N ≤ 100 |
| 2 | 30 | S 只包含 a 與 b |
| 3 | 50 | 無額外限制 |

時間限制 1 秒，記憶體限制 256 MB。
