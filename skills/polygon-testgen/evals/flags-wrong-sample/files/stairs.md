# 第一題：破損的樓梯 (Stairs)

阿華要從第 0 階走到第 N 階。每一步可以往上走 1 階、2 階或 3 階。但是樓梯有 M 階已經破損，不能踩在破損的階上（第 0 階與第 N 階一定完好）。

請問阿華有幾種不同的走法？答案可能很大，請輸出除以 1000000007 的餘數。

## 輸入說明

第一行有兩個整數 N、M（1 ≤ N ≤ 100000，0 ≤ M < N）。
若 M > 0，第二行有 M 個相異整數 b_1, …, b_M（1 ≤ b_i < N），代表破損的階。

## 輸出說明

輸出一個整數，代表走法數除以 1000000007 的餘數。

## 範例輸入 1

```
4 0
```

## 範例輸出 1

```
8
```

## 範例輸入 2

```
5 1
2
```

## 範例輸出 2

```
5
```

## 評分說明

| 子題 | 分數 | 額外限制 |
|---|---|---|
| 1 | 30 | N ≤ 30，M = 0 |
| 2 | 70 | 無額外限制 |

時間限制 1 秒，記憶體限制 256 MB。
